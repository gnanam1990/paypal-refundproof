# Implementation plan

1. M00 defines canonical identities, states, schemas, and failing property tests.
2. M01 adds migrations, tenant-aware authentication, authorization, audit storage, restart recovery, and transactional scheduling.
3. M02 adds redacted evidence admission, schema-constrained AI proposal generation, citations, and human correction.
4. M03 implements exact approval, policy evaluation, full-refund consent, expiry, and revision invalidation.
5. M04 integrates PayPal sandbox, fault injection, unknown-outcome handling, authoritative reconciliation, and duplicate prevention.
6. M05 completes accessible UI, observability, deployment configuration, clean-checkout tests, documentation, and submission artifacts.

Each module begins with a failing test and ends with exact commands, exit codes, test counts, redacted evidence, commit SHA, and remaining risks. Do not begin the next module while its dependency handoff is incomplete.
